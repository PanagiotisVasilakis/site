# Cleanup Review Notes

These items were intentionally not removed because they may still be useful, are part of production history, or need a product/operations decision.

## Assets

- `public/qr/site.svg` is generated by `npm run qr` but the app currently uses `public/qr/site.png` for metadata, manifest icons, and the QR info page. Keep until the QR generation workflow is confirmed to no longer need the SVG.
- `public/house/**`, `public/moments/**`, `public/qr/site.png`, `public/app.webmanifest`, `public/sw.js`, `public/precache.json`, `public/critical-precache.json`, and `public/version.json` are referenced by app pages, data files, metadata, service worker logic, or build scripts and were kept.

## Routes And APIs

- `src/app/api/dev/alerts/verify-spike/route.ts` is a non-production alert testing endpoint guarded by `NODE_ENV` and optional admin secret. It is not linked from the app, but may be useful for operational testing.
- `src/app/api/portal/dev-mint-session/route.ts` appears to be a development helper documented by older refactor notes. Review whether it should remain available outside local development.

## Prisma And Database

- `prisma/schema.prisma` and `prisma/migrations/**` were left untouched. Some models such as MFA, cache, metrics, and logs are not obviously exercised by current runtime code, but removing schema or migration history is a database migration decision, not a cleanup-only change.
- `data/secure/*.enc.json` was kept. `feature-flags.enc.json` and `checkin-preferences.enc.json` are read by active routes/utilities; `secure-data.enc.json` is read by `scripts/query-guests.ts`.
- Tracked env files such as `.env.test`, `.env.production`, and `.env.staging` should be reviewed for live credentials before sharing or publishing the repository.

## Documentation
